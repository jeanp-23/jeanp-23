## 🚀 Proyecto Destacado / Trabajo de Grado

### 🔬 Sistema de Visión por Computadora para Análisis Postural y Biomecánico
*Aplicativo de software en tiempo real diseñado para el análisis biomecánico postural, integrando técnicas avanzadas de procesamiento de imágenes e Inteligencia Artificial.*

* **Procesamiento e IA:** Captura e interpretación de puntos clave del cuerpo en tiempo real utilizando **Python**, **OpenCV** y **MediaPipe** para análisis biomecánico, postura y detección de patrones.
* **Integración y Arquitectura:** Estructuración de flujos de datos para el diagnóstico postural sistemático, optimización de algoritmos para baja latencia y generación de reportes biomecánicos.

## 💻 Proyectos Activos y de Impacto

### 📦 Nido.OS — Plataforma ERP E-Commerce Analítica e Inteligente
*Evolución de un sistema ERP hacia una arquitectura distribuida orientada a microservicios e IA.*

* **Core Backend:** Arquitectura modular construida con **NestJS**, **TypeORM** y **PostgreSQL**, garantizando transacciones ACID y alta disponibilidad.
* **Módulo de Predictive ML:** Modelo de clasificación con **Scikit-Learn** en Python para predecir riesgos de morosidad y abandono de apartados (*"El Baúl"*).
* **Agente RAG de Atención (WhatsApp):** Asistente conversacional multi-agente utilizando **LangChain**, **FastAPI**, **n8n** y LLMs para la consulta de inventarios, saldos y recomendaciones en tiempo real.
* **Data Analytics & BI:** Pipelines ETL en Python para el cálculo de métricas clave como CLV (Customer Lifetime Value) y margen neto por SKU.
